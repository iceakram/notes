# IceNote - Feature Documentation

## Core Features

### 1. Notes Management
- **Create Notes**: Click "New Note" button or use the "Create Note" CTA
- **Edit Notes**: Click on any note card to open the editor
- **Delete Notes**: Use the trash icon in the editor header
- **Auto-save**: Changes are automatically saved after 1 second of inactivity
- **Pin Notes**: Keep important notes at the top of your list

### 2. Rich Text Editing
- **Bold Text**: Use the B button or Ctrl+B
- **Italic Text**: Use the I button or Ctrl+I  
- **Headings**: Use the # button to add markdown headings
- **Lists**: Use the list button to create bullet points
- **Code Blocks**: Use the code button for inline code

### 3. Organization
- **Tags**: Add multiple tags to categorize notes
- **Search**: Real-time search across note titles, content, and tags
- **Folders**: Infrastructure ready for folder organization
- **Pin to Top**: Pin important notes for quick access

### 4. Themes
- **Light Mode**: Clean ice-white background with frost blue accents
- **Dark Mode**: Deep navy background with glassmorphic cards
- **Auto-persist**: Your theme preference is saved locally

### 5. User Interface
- **Glassmorphism**: Beautiful frosted glass effect on cards
- **Smooth Animations**: Subtle fade-ins, slide-ups, and transitions
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Empty States**: Helpful guidance when no notes exist

### 6. Privacy & Storage
- **Local Storage**: All notes stored in browser localStorage
- **No Tracking**: Zero analytics or external data collection
- **Offline First**: Works completely offline after initial load

## Keyboard Shortcuts

- `Ctrl + N` - Create new note
- `Ctrl + F` - Focus search
- `Ctrl + B` - Bold text
- `Ctrl + I` - Italic text
