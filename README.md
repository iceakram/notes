# IceNote ❄️

Ultra-professional, minimalist notes application with icy clarity and precision.

## Features

- ✨ **Beautiful Glassmorphic UI** - Smooth glass-like cards with backdrop blur
- 🎨 **Dark/Light Mode** - Ice-dark theme for late-night writing
- ⚡ **Auto-save** - Never lose your work
- 📝 **Rich Text Editor** - Headings, bold, italic, lists, and code blocks
- 🔍 **Smart Search** - Find notes instantly
- 🏷️ **Tags & Organization** - Keep everything organized
- 📌 **Pin Notes** - Keep important notes at the top
- ⌨️ **Keyboard Shortcuts** - Work faster with shortcuts
- 📱 **Fully Responsive** - Works on all devices
- 🎯 **Privacy First** - All data stored locally

## Tech Stack

- **Framework**: Next.js 14+ with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom design tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Keyboard Shortcuts

- `Ctrl + N` - Create new note
- `Ctrl + F` - Search notes
- `Ctrl + B` - Bold text
- `Ctrl + I` - Italic text
